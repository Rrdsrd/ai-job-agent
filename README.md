# AI Job Agent

A Python-based job search and matching dashboard built with Streamlit.

## Features

- Fetch jobs from multiple Greenhouse company boards
- Filter Data Engineering and AI Automation roles
- Identify India-location opportunities
- Rank jobs using candidate skill keyword matching
- Filter jobs by company, career track and match score
- Export filtered jobs to CSV

## Tech Stack

- Python
- Streamlit
- Pandas
- Requests

## Run Locally

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py
